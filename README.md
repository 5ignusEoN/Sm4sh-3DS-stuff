Different files are used for different aspecs of modding, dumping, and viewing files for Smash Bros. 3DS, or Sm4sh 3DS.

----------------------------------
Firstly though, in order to even create and apply mods on **Real Hardware** and **LEGALLY** you'll need to dump your game, whether it's cartridge or digital, so first, you'll need a few things.
- A modded 3DS, if you don't already have a modded system, there is a [tutorial](https://3ds.hacks.guide)
- [GodMode9 (GM9)](https://github.com/d0k3/GodMode9/releases/)
- Once you have all of this, I would [recommened following this tutorial](https://gamebanana.com/tuts/13585) but ofcourse, if you have a (**LEGAL**) dump of the game and on an emulator, like citra, it is already modded.
- **Dumping from Real Hardware is recommened if you plan on making mods**



--------------------------------------
**Sound modding** requires the following:
- BrawlBox
- Nus3Bank Editor
- [Audacity](https://www.audacityteam.org/download/)
- [Python 2.7](https://www.python.org/download/releases/2.7/) or [3.5](https://www.python.org/downloads/release/python-350/);
- Here is a link to the [tutorial on Gamebanana](https://gamebanana.com/tuts/13016)
